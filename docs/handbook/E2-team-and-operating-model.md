# E2 Team and operating model

## E2.1 Core team (Phases 1–2)

Indicative roles; FTE figures are planning assumptions to be confirmed at scoping.

| Role | Phase 1 | Phase 2 | Owns |
|---|---|---|---|
| Solution architect / delivery lead (Senior Manager) | 0.5 | 1.0 | Architecture integrity, scope, client relationship, quality, commercial discipline |
| Ontology lead / knowledge engineer | 1.0 | 1.0 | `ontology/`, shapes, rules, change board |
| Graph / data engineer | 1.0 | 2.0 | Compiler, stores, connectors, mirror jobs |
| AI engineer | 0.5 | 1.0 | Access layer, `get_context`, answer-contract harness |
| Domain SME: refining operations & planning | 0.25 | 0.5 | Process spine, material, economics |
| Domain SME: reliability & integrity | 0.25 | 0.5 | Asset spine, problems, rules, hypothesis review |
| Front-end / visualisation (part time) | 0.25 | 0.25 | Explorer, lenses |

## E2.2 Global delivery model

| Work | Best placed | Why |
|---|---|---|
| Client workshops, SME validation, value case | Onshore / client-facing | Access to plant knowledge and decision owners |
| Ontology, compiler, connectors, tests, insight library | Global delivery centre | Repeatable engineering and reusable assets |
| Hypothesis review | Client SMEs with the domain modeller | Accountability stays with the client |

## E2.3 Delegation and growth

| Person | Develops toward |
|---|---|
| Ontology lead | Owning the change board independently by end of Phase 2 |
| Graph engineer | Leading connector patterns across clients |
| AI engineer | Owning the access-layer product and answer-contract testing |

The delivery lead's job is to make each of these roles independent of the lead, so the accelerator scales beyond one person.

## E2.4 Working cadence

| Ritual | Cadence | Output |
|---|---|---|
| Sprint planning / review | 2 weeks | Backlog items from [E1](E1-roadmap.md) closed with demos on real questions |
| Ontology change board | 2 weeks | ADR entries, releases |
| Hypothesis review | Weekly | Validated / rejected edges, rule precision |
| Steering with sponsor | Monthly | Decisions, risks, value tracking |
